# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML and CSS, one page (`index.html`, `styles.css`), no build step.

## Users

Recruiters and hiring managers reading Himani's job applications; secondarily Himani herself, as a personal home on the web.

## Product Purpose

A one-page portfolio for Himani Nizam, software engineer. Success: a recruiter learns role, stack, employers and results in under a minute, then emails her, downloads the resume, or opens GitHub or LinkedIn.

## Positioning

Backend integration and performance on enterprise systems: event-driven trading services at Voya Financial and a cloud ERP at Cognizant, both with measured results from the resume.

## Capabilities and Constraints

- Actions: email (primary), download resume PDF, GitHub, LinkedIn.
- Phone number stays off the public page.

## Evidence on Hand

- `Himani_Nizam_Resume.pdf`: every fact, figure and date on the page comes from it.
- `Professiona_Photo.jpeg`: professional headshot, 800 x 800, warm off-white background.
- LinkedIn: https://www.linkedin.com/in/himanias87/ · GitHub: github.com/nizamhimani · Email: nizamhimani16@gmail.com
- Absent, never to be invented: testimonials, employer logos, project screenshots, project repo links, metrics beyond the resume.

## Product Principles

1. Every claim is a resume fact; numbers are never rounded up or added.
2. The four contact routes are reachable from the first screen.
3. Editorial restraint: the type and the results carry the page, not decoration.
